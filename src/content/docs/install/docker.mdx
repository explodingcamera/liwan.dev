---
title: Installing liwan Using Docker
---

import { Steps } from "@astrojs/starlight/components";

<Steps>

1. **Run liwan**

   ```sh
   docker run -d --name liwan \
     -p 127.0.0.1:9042:9042 \
     -v liwan-data:/data \
     -e LIWAN_BASE_URL=https://a.example.com \
     -e LIWAN_TRUSTED_PROXIES='*' \
     ghcr.io/explodingcamera/liwan:1.8
   ```

   - `LIWAN_BASE_URL` is your instance's public URL. Replace `https://a.example.com` with yours.
   - `LIWAN_TRUSTED_PROXIES='*'` accepts forwarded client IPs from any connecting peer. See step 3 for when to restrict it.

2. **Find the setup URL**

   Check the logs and open the setup URL to create your first user, project, and entity:

   ```bash title="liwan"
   docker logs liwan
   ```

   ```plaintext "http://localhost:9042/setup?t=1234567890" "liwan --help"
   It looks like you're running liwan for the first time!
   You can get started by visiting: http://localhost:9042/setup?t=1234567890
   To see all available commands, run `liwan --help`
   ```

3. **Set up public access**

   For a public instance, [add a reverse proxy for HTTPS and public routing](/guides/reverse-proxy/) and keep liwan's port inaccessible to the public. `*` trusts forwarded client IPs from any peer. Other containers on a shared Docker bridge can reach liwan directly, so use the proxy's address instead if they are not trusted. See the [trusted proxy guidance](/guides/reverse-proxy/#client-ip-headers).

</Steps>
